# PROTOCOLO ANTI-BUCLE DE GOBERNANZA (GÉNESIS - ANTI-LOOP)
1. **Regla del Límite de Falla**: Si un comando de gobernanza (ej. `logix audit`, `logix takeover`, `logix baseline`, `verify_veracity.dart`) falla de forma consecutiva **dos veces** debido a un error de integridad, firma RSA, o incoherencia semántica del Core, el agente tiene prohibido de forma absoluta intentar resolverlo de forma autónoma generando scripts alternativos, eliminando metadatos o probando bypasses no documentados.
2. **Parálisis de Diagnóstico Activo**: Ante la tercera falla consecutiva de un comando crítico, el agente debe cesar de inmediato toda ejecución de comandos, entrar en "Silencio Forense", reportar al PO de forma concisa el log del error de integridad y esperar instrucción humana. Operar en bucle intentando auto-sanar fallas de gobernanza constituye Negligencia Técnica.
