## Objetivo
Crear un módulo NestJS **nuevo e independiente** (`admin-actions`) que exponga un endpoint para que el administrador restablezca la contraseña de cualquier usuario (excepto otros administradores), sin modificar los controladores o servicios existentes.

---

> ⚠️ CAUTION
> - **NO** modificar `UsersController`, `UsersService`, `AuthController` ni `AuthService`.
> - **NO** añadir columnas a las tablas existentes de la base de datos.
> - **NO** usar SMTP ni envío de correos en este módulo.
> - Toda lógica nueva debe residir en archivos nuevos bajo `backend/src/admin-actions/`.

---

## Entregables

### Archivos a Crear (Nuevos — no editar ninguno existente)

#### `backend/src/admin-actions/admin-actions.module.ts`
Módulo NestJS que importa `TypeOrmModule.forFeature([User, SystemConfig])` y registra el controller y service.

#### `backend/src/admin-actions/admin-actions.controller.ts`
Expone **UN solo endpoint**:
```
PATCH /admin-actions/users/:id/reset-password
```
- Decorado con `@UseGuards(AuthGuard)` para requerir autenticación.
- Valida en el guard que el usuario autenticado tenga `role === 'admin'`.
- Cuerpo del request: `{ newPassword: string }` (mínimo 8 caracteres).

#### `backend/src/admin-actions/admin-actions.service.ts`
Lógica interna del servicio:
1. **Validar jerarquía**: Busca el usuario destino. Si su `role === 'admin'`, lanzar `ForbiddenException('No se puede restablecer contraseña de otro administrador')`.
2. **Hashear nueva clave**: Importar y reutilizar `hashPassword` de `backend/src/auth/crypto.util.ts` (solo importar, NO modificar).
3. **Actualizar contraseña**: Ejecutar `userRepository.update(id, { password: hashedPassword })` directamente.
4. **Registrar flag de cambio obligatorio**: Insertar o actualizar registro en `system_configs` con clave `force_pwd_change:${userId}` y valor `"true"`.
5. **Retornar**: `{ success: true, message: 'Contraseña restablecida. El usuario deberá cambiarla en su próximo acceso.' }`
