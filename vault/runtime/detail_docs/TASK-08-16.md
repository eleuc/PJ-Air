## Objetivo
Crear un endpoint autenticado para que el usuario pueda **cambiar su propia contraseña** y, si tenía un flag `force_pwd_change` activo, éste sea eliminado de `system_configs` al completarse exitosamente.

---

> ⚠️ CAUTION
> - **NO** modificar `UsersController` ni `UsersService` existentes.
> - **NO** añadir columnas a la base de datos.
> - El nuevo endpoint debe vivir en el módulo `admin-actions` creado en TASK-08-14, o en un nuevo `self-service` controller si el PO lo prefiere.
> - **NO** usar SMTP.

---

## Archivos a Crear/Modificar

### Nuevo endpoint en `backend/src/admin-actions/admin-actions.controller.ts`
```
PATCH /admin-actions/me/change-password
```
- Requiere autenticación (`@UseGuards(AuthGuard)`).
- Extrae el `userId` del token JWT autenticado.
- Cuerpo: `{ currentPassword: string, newPassword: string }`.

### Lógica en `backend/src/admin-actions/admin-actions.service.ts`
Método `changeOwnPassword(userId, currentPassword, newPassword)`:
1. Buscar el usuario por ID con `select: ['password']`.
2. Verificar `currentPassword` contra el hash almacenado:
   - Si es PBKDF2 (contiene `:`): usar `verifyPassword` de `crypto.util.ts`.
   - Si es bcrypt (inicia con `$2`): usar `bcrypt.compareSync`.
3. Si la verificación falla → lanzar `UnauthorizedException('Contraseña actual incorrecta')`.
4. Hashear `newPassword` con `hashPassword` de `crypto.util.ts`.
5. `userRepository.update(userId, { password: hashedNewPassword })`.
6. **Eliminar el flag**: `systemConfigRepository.delete({ key: \`force_pwd_change:\${userId}\` })`.
7. Retornar: `{ success: true, message: 'Contraseña actualizada correctamente.' }`.

## Turno Adversarial (Pre-Código)
**Riesgo**: Si el usuario tiene contraseña bcrypt (antigua) y no ha iniciado sesión desde la migración, la verificación debe contemplar ambos formatos.
**Mitigación**: El método de verificación debe manejar el mismo branching que ya existe en `auth.service.ts` (PBKDF2 vs bcrypt). Copiar la lógica de verificación del método `login` como referencia, sin moverla ni reutilizarla directamente para evitar acoplamiento.
